# Youtube Audio Downloader

Python script that downloads audio from a YouTube video and converts it to MP3 using yt-dlp and FFmpeg.

## Requiriments
- Python 3
- yt-dlp
- ffmeg (you can install it easier using Chocolatey running the following command: *choco install ffmpeg*)

## How to use it
1. You must write the url's in the *urls* file, one line for each audio you want.
2. Run the script

```bash
python main.py
```
